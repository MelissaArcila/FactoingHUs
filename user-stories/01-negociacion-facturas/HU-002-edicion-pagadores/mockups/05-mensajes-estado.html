Estados de la Aplicación

1. Toast Notifications (Notificaciones Emergentes)

Mensajes temporales que aparecen en la esquina superior derecha de la pantalla y se ocultan automáticamente después de 4-5 segundos.

Éxito - Guardado Correcto

¡Éxito!
Datos del pagador actualizados correctamente

Error - Fallo en el Guardado

Error al guardar
No se pudieron guardar los cambios. Por favor, intente nuevamente.

2. Estado de Carga

Indicador visual que se muestra mientras se procesa la petición al servidor. Aparece como overlay sobre el contenido.

Guardando cambios...

3. Mensajes Inline (Dentro de la Tabla)

Mensajes que aparecen directamente en la interfaz, sobre la tabla después de realizar una acción.

Éxito

Datos del pagador actualizados correctamente

Error

No se pudieron guardar los cambios. Por favor, intente nuevamente.

4. Banner Alerts (Alertas Destacadas)

Mensajes más prominentes que ocupan todo el ancho y pueden permanecer visibles hasta que el usuario los cierre.

Éxito

Cambios guardados exitosamente
La información del pagador IMPORGLOBEX S.A.S ha sido actualizada. Las nuevas tasas se aplicarán a partir de ahora.

Error

Error al actualizar el pagador
No se pudo completar la operación debido a un error en el servidor. Por favor, intente nuevamente en unos momentos o contacte al administrador si el problema persiste.

Recomendaciones de Uso

Toast Notifications: Ideales para acciones rápidas y feedback inmediato. Se ocultan automáticamente.

Loading State: Siempre mostrar durante operaciones asíncronas (llamadas API). Previene clicks duplicados.

Inline Messages: Buenos para confirmaciones que necesitan permanecer visibles mientras el usuario continúa trabajando.

Banner Alerts: Para mensajes importantes que requieren atención del usuario antes de continuar.
