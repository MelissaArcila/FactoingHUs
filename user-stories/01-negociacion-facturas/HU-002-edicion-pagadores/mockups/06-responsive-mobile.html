Vista Responsive - Mobile y Tablet

Consideraciones de Diseño Responsive
Mobile (320px - 768px):
  • Modal ocupa el 100% de la pantalla
  • Botones apilados verticalmente en footer
  • Campos de formulario con padding generoso para touch
  • Font-size mínimo de 14px para legibilidad
Tablet (768px - 1024px):
  • Modal ocupa 90% del ancho con margen centrado
  • Botones pueden ir horizontalmente si hay espacio
  • Mantiene estructura similar al desktop
